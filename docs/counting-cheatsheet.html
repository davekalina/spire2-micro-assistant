Micro Assistant — Counting Sources

v0.3.0 · badges above the hovered card and the End Turn button
ON CARD: 3 current count — this play advances it 9 gold — this play triggers it X this play breaks it / gets nothing ● bare icon — this play triggers it (no counter) 6 aqua — card held for play: the value it’s about to become ON END TURN: verdict badge — hover it in game for the exact “Will / Will NOT” text

Counts are read from the game’s own values, so badges always match the relic bar and power icons. Not tracked (by design): locks such as Sloth/Smoggy/Ringing and Normality, end-turn reversals (Tender, Monologue), Unsettling Lamp, and out-of-combat counters — the game already communicates those.  ·  Micro Assistant · github.com/davekalina/spire2-micro-assistant
